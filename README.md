# Backend API (FastAPI + Socket.io)

Core backend for Smart Education Canvas (Cosmohack1):
- Node data management (CRUD)
- Connection/edge modeling
- Architecture info (API, DB schema, microservice)
- Annotation/comments endpoints
- Real-time collab with Socket.io
- Data integration API (Sheets/JSON)

## Structure
- /nodes (GET, POST, PUT, DELETE)
- /edges (connections)
- /annotations (comments/sticky notes)
- /sync (WebSocket events)
- /ai (Gemini assistant, diagram/documentation automation)
