# Smart Education Canvas (Cosmohack1)

A collaborative, editable visual platform for mapping and evolving interconnected smart education projects. Features interactive, draggable nodes; glowing animated data-flow lines; dropdowns with tech stack/expert commentary; inputs-outputs blocks; annotation layer; and multi-user real-time sync.

## Tech Stack
- React.js (UI)
- D3.js/Three.js (visualization, graph, glowing effects)
- TailwindCSS + Framer Motion (modern animation)
- FastAPI/Node.js (backend)
- MongoDB/Firebase (database)
- Socket.io (real-time collaboration)
- Gemini/AI APIs (co-pilot assistant)

## Features
- Editable, animated canvas with movable nodes (SkillGraph Navigator, AI Mentor, MindMapify, etc.)
- Color-coded categories (AI, Visualization, Analytics, etc.)
- Glowing data-flow and synergy connections
- Hover reveals Input → Process → Output
- Expandable dropdowns: Tech Stack & Expert Commentary
- Sticky comments/notes per node and connection
- Embed backend/API/database/schema/code info per node
- Live data integration (Google Sheets, JSON, REST)
- Multi-user editing, chat/collab
- AI Gemini-powered auto-diagram/documentation
- Export as JSON/PNG/HTML
